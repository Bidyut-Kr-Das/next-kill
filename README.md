# next-kill

Find and delete `.next` build folders fast. Like [npkill](https://npmjs.com/package/npkill), but for Next.js build output.

```sh
npx next-kill            # scan current directory
npx next-kill ~/projects # scan another directory
npx github:bidyut-kr-das/next-kill   # straight from GitHub
```

Scans recursively for `.next` folders, shows them with their sizes, and lets you delete the ones you pick.
`node_modules` and `.git` are skipped (use npkill for `node_modules`).

| Key | Action |
| --- | --- |
| up / down, j / k, pgup / pgdn, home / end | move |
| space / delete | delete selected `.next` |
| q / esc / ctrl+c | quit |

Piped output (`npx next-kill | sort -h`) prints `size  path` lines and never deletes anything.

## Why it's fast

- No runtime dependencies.
- Bigger libuv threadpool (Node's default of 4 threads throttles fs work); one `readdir` per directory, no per-entry `stat`.
- Sizes are computed only after the scan finishes, so the scan gets the whole threadpool.
- Delete first renames the folder (instant), then removes it in the background.

## Warning

Deletion is permanent. `.next` is regenerated by `next dev` / `next build`, so deleting it only costs a rebuild.
